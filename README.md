# Adverting

Front end for Adverting, a daily-brief tool for digital marketing agencies. Every
morning it shows what is trending in each client's sector and one action per
client, and ranks which client needs attention first. Includes a live trend
ticker, a sample brief, a client priority demo and an ROI calculator.

Built solo, 2026. Next.js, TypeScript, Tailwind, Framer Motion, GSAP.

Status: not deployed.
